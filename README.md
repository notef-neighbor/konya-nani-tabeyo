# 今夜なに食べよ？ 🏮

「今夜の晩ごはん、何にしよう…」と迷ったときに、夜の屋台・居酒屋のお品書き風ルーレットで楽しく決めてくれるシングルページWebアプリです。

## 主な機能

- **ワンタップでお品書きガチャ**：大きなボタンを押すと、木札ディスプレイがシャッフルされて今夜の一品を決定します（紙吹雪・効果音つき）。
- **48品のバリエーション豊かな初期メニュー**：定番ごはん（20品）・ちょっと贅沢（16品）・変わり種（12品）を、それぞれひとことコメント付きで収録しています。
- **気分フィルター**：その日の気分に合わせてジャンルを絞って回せます。
- **自分好みにカスタマイズ**：好きな料理の追加・削除ができ、変更内容はブラウザの `localStorage` に自動保存されます。初期リストへのリセットも可能です。

## 使い方・公開方法

HTML / CSS / JavaScript のみで構成された**完全な静的サイト**です（バックエンド・ビルド手順・外部フレームワーク不要）。

- **ローカルで開く**：`index.html` をそのままブラウザで開くだけですぐに使えます。
- **GitHub Pages で公開する**：リポジトリのルートに `index.html` を配置しているため、`main` ブランチのルート（`/`）をそのまま GitHub Pages の公開元として設定できます。

## ファイル構成

- `index.html` — アプリ本体（マークアップ）
- `styles.css` — 夜の屋台・居酒屋風デザイン＆アニメーション
- `app.js` — ガチャ抽選・お品書きデータ・`localStorage` 永続化・効果音・紙吹雪エフェクト
- `README.md` — この説明書
